# Preserved RedVsBlue source

`RedVsBlue_Phase1_Source.zip` is a read-only snapshot of the teammate implementation used as the Phase 1 research baseline. `manifest.sha256` records every archived file and hash. `source-state.txt` records the original Git HEAD and working-tree status.

Do not edit the archive while integrating features. Adaptations belong in the active HideAndSeek source tree and should cite `Documentation/TeammateResearchBaseline.md`.
